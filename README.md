## Описание проекта

Цель проекта — построить модель машинного обучения, которая предсказывает **прочность бетона на сжатие** на основе состава бетонной смеси и возраста образца.

Проект решает задачу **регрессии с учителем**: по числовым характеристикам компонентов смеси модель оценивает целевую переменную — прочность бетона в мегапаскалях.

---

## Цель

Разработать модель, способную предсказывать значение:

> **Concrete compressive strength** — прочность бетона на сжатие, МПа.

На основе следующих признаков:

- количество цемента;
- количество доменного шлака;
- количество золы-уноса;
- количество воды;
- количество суперпластификатора;
- количество крупного и мелкого заполнителя;
- возраст бетонного образца.

## Этапы работы

### 1. Подготовка данных

На этапе подготовки были выполнены следующие действия:

- загружен датасет из файла `Concrete_Data.xls`;
- изучена структура таблицы;
- проверены типы данных;
- проверено наличие пропусков;
- исправлены некорректные названия столбцов;
- обнаружены и удалены дубликаты.

### 2. Исследовательский анализ данных

Для анализа распределений и взаимосвязей были построены:

- гистограммы распределения признаков;
- графики средних значений;
- boxplot-графики для поиска выбросов;
- матрица корреляции `phi_k`;
- scatterplot-графики зависимости признаков от целевой переменной.

### 3. Feature Engineering

В ходе анализа были выполнены дополнительные преобразования признаков:

- удалён признак `Fly Ash`, так как он слабо коррелировал с целевой переменной и ухудшал качество модели;
- признак `Age` был преобразован в категориальный `Age_class`;
- к признаку `Water` была применена логарифмизация;
- для числовых признаков были добавлены полиномиальные признаки 2-й и 3-й степени;
- данные были масштабированы с помощью `StandardScaler`.

### 4. Обучение моделей

Для выбора лучшей модели были протестированы несколько алгоритмов:

| Модель | Подбор гиперпараметров |
|---|---|
| `LinearRegression` | без дополнительных параметров |
| `Ridge` | `alpha` |
| `Lasso` | `alpha` |
| `SVR` | `C`, `kernel` |
| `DecisionTreeRegressor` | `max_depth`, `min_samples_split` |

Подбор модели и гиперпараметров выполнялся с помощью `RandomizedSearchCV` с кросс-валидацией.

---

## Лучшая модель

По результатам экспериментов лучшей моделью стала:

```python
Ridge(alpha=0.1, random_state=42)
```

### Качество модели

| Метрика | Значение |
|---|---:|
| `R²` на кросс-валидации | 0.85 |
| `R²` на тестовой выборке | 0.84 |

Значение `R² = 0.84` означает, что модель объясняет примерно **84% вариативности целевой переменной** на тестовых данных.

## Pipeline проекта

В проекте используется единый pipeline, который объединяет этапы предобработки данных и обучения модели.

```python
Pipeline(
    steps=[
        ('preprocessor', preprocessor),
        ('regressor', Ridge(alpha=0.1, random_state=42))
    ]
)
```

Такой подход позволяет:

- избежать утечки данных;
- упростить повторное обучение модели;
- удобно подбирать гиперпараметры;
- сделать код более чистым и воспроизводимым.
